# Serein с обходом DPI

Форк нативного клиента Discord [Serein](https://github.com/ViceVerse-cz/Serein) на Rust (egui/wgpu), в который встроен обход DPI на базе [zapret](https://github.com/bol-van/zapret) и сборки стратегий [Flowseal](https://github.com/Flowseal/zapret-discord-youtube).

Оригинальный клиент не умеет обходить блокировки, и в России без обхода он просто не подключается к Discord. Этот форк поднимает обход сам, до того как клиент попытается авторизоваться.

## Что добавлено к оригиналу

В настройках появилась страница «Обход DPI» с двумя режимами.

Авто: перебирает стратегии по порядку и останавливается на первой, после которой Discord реально отвечает. Следующий запуск начинает с той же стратегии, поэтому в норме это одна проверка, а не полный перебор.

Вручную: прогоняет все стратегии и показывает список с результатами. Рабочие строки подсвечены, по клику выбирается нужная.

Дополнительно:

- при старте приложение проверяет, не поднят ли обход уже, включая случай, когда zapret установлен службой, и не запускает второй экземпляр;
- если обход не поднят, он стартует автоматически вместе с клиентом;
- для запуска winws с правами используется задача планировщика, которая создаётся один раз при установке, дальше запросов UAC нет;
- запуск идёт через wscript, поэтому окна консоли не появляются;
- рабочая стратегия сохраняется и остаётся включённой после проверки.

## Как это работает

Задача планировщика SereinZapret с максимальными правами запускает сгенерированный скрипт, тот поднимает zapret\bin\winws.exe с параметрами выбранной стратегии. Вторая задача SereinZapretStop гасит winws, когда обход отключают: schtasks /end завершает только хост, а дочерний процесс остаётся.

Параметры стратегий лежат в crates/zapret/data/strategies.json. Каталог собран из general*.bat сборки Flowseal скриптом tools/gen-strategies.ps1.

Проверка стратегии: запрос к трём адресам Discord (discord.com/api/v10/gateway, gateway.discord.gg, cdn.discordapp.com). Успехом считается любой ответ сервера, включая 403 от CDN, потому что это значит, что TLS и запрос прошли. Стратегия считается рабочей, если ответили минимум два адреса из трёх.

## Установка
https://github.com/StepashKA5/SereinDPI/releases

Установщик: serein-<версия>-setup.exe. Ставится в профиль пользователя, при установке один раз запрашивает права администратора, чтобы зарегистрировать задачи планировщика.

Портативная сборка: распаковать архив и запустить serein.exe. При первом запуске приложение само попросит права и зарегистрирует задачи.

Логин подхватывается из хранилища учётных данных Windows, поэтому заново входить не нужно, если клиент уже был установлен.

## Обновления

.github/workflows/sync-upstream.yml раз в сутки вливает свежий main из апстрима в форк.

.github/workflows/refresh-zapret.yml раз в сутки скачивает последнюю сборку Flowseal, пересобирает каталог стратегий и обновляет бинарники в packaging/windows/zapret.

.github/workflows/fork-build.yml собирает установщик и портативный архив на каждый пуш, релиз публикуется по тегу v*.

## Правовая оговорка

Проект не связан с Discord. Использование стороннего клиента с обычным аккаунтом нарушает условия Discord и может привести к блокировке аккаунта. В России личное использование средств обхода блокировок не запрещено, но реклама и продвижение таких средств с 1 сентября 2025 года наказываются по КоАП. Прежде чем распространять сборку публично, оцените риски самостоятельно.
