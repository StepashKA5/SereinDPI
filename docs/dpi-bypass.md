# DPI-обход внутри Serein (форк)

Статус: **каркас** — каталог стратегий, рендер аргументов, скоуп фильтра,
обёртка службы и probe уже в коде (`crates/zapret`). UI-страница и служба-агент
ещё не написаны.

## Почему не расширением

Расширения Serein — Wasm без host-импортов: ни процессов, ни файлов, ни сокетов
(`docs/extensions.md`). Единственный сетевой капабилити `api_proxy` проксирует
только REST. Запустить `winws.exe` из плагина нельзя.

## Из чего состоит решение

```
Serein (GUI, без админа)
  └─ кнопки «Найти обход» / «Подключить»
        │  пишет strategy.json  (%LOCALAPPDATA%\serein-zapret\)
        │  schtasks /run | /end  SereinZapret
        ▼
Задача планировщика SereinZapret («от имени пользователя, с наивысшими правами»)
  └─ cmd /c run.cmd  →  читает strategy.json  →  winws.exe <args>
        ▼
winws.exe + WinDivert → desync на уровне пакетов
```

Почему задача, а не служба: WinDivert требует администратора, а задача,
зарегистрированная с `RunLevel Highest`, запускается **без UAC** (её создаёт
установщик один раз, при первом включении). Не нужен отдельный exe-агент,
SCM-цикл и правка SDDL службы: `run.cmd` читает стратегию из файла, поэтому
перебор работает без пересоздания задачи. `schtasks /end` гасит всё дерево
процессов, включая `winws`.

Альтернатива — служба `serein-zapret` с `binPath=serein.exe --zapret-agent` и
SDDL-правами `RP/WP` для `IU`; она надёжнее переживает перезагрузку, но требует
`windows-service` и больше кода. Планировщик проще и достаточен.

## Как работает «Найти обход»

1. Каталог `crates/zapret/data/strategies.json` — 22 стратегии Flowseal,
   сгенерированы `tools/gen-strategies.ps1` из `general*.bat`.
2. Для каждой: записать конфиг → `sc stop` → `sc start` → дождаться `RUNNING` →
   `probe(DISCORD_GATEWAY)` (реальный HTTPS через системный `curl.exe`).
3. Первая стратегия, у которой `https://discord.com/api/v10/gateway` отвечает
   2xx, считается рабочей и запоминается.

Проверять TCP-коннектом бессмысленно: блокировка обычно после ClientHello.

## «Только для этого приложения»

WinDivert **не умеет фильтровать по процессу** — в языке фильтров есть только
адреса, порты и payload. Отсюда два варианта в `crates/zapret/src/scope.rs`:

- `Scope::Discord` (по умолчанию) — только порты Discord (`80/443/2053/2083/
  2087/2096/8443` TCP, `443` + `19294-19344` + `50000-50100` UDP). Обход не
  трогает YouTube, игры и прочий трафик. Формально под него попадает и
  официальный клиент Discord, если он запущен.
- `Scope::AppPorts { low, high }` — фильтр по `tcp.SrcPort`/`udp.SrcPort`.
  Чтобы он действительно означал «только Serein», все сокеты приложения должны
  биндиться в этот диапазон:
  - voice UDP — легко (`UdpSocket::bind`), 2 места;
  - gateway/voice WS — нужен свой `TcpSocket::bind` + `client_async_tls_with_config`
    (`tokio-tungstenite` 0.30 это умеет), 4 места;
  - REST и CDN (`reqwest` 0.13.5) — **нельзя** без вендоринга: у
    `reqwest::ClientBuilder` только `local_address(IpAddr)`, у
    `hyper-util::HttpConnector` порт всегда эфемерный. Восемь отдельных клиентов
    (avatars, downloads, audio, video, updates, uploads...) пришлось бы вести
    через собственный loopback-релей.

Поэтому сейчас реализуется `Scope::Discord`; `AppPorts` оставлен как задел.

## Сборка

Локально нужен MSVC (сейчас на машине его нет) — поэтому сборка идёт в
GitHub Actions: `.github/workflows/fork-build.yml` собирает установщик на
`windows-latest` при каждом пуше и публикует релиз на тег `v*`.

```powershell
cargo xtask package     # dist-installer\serein-<version>-setup.exe
```

Ассеты zapret (winws.exe, WinDivert, cygwin1.dll, фейки, списки) лежат в
`packaging/windows/zapret/` и должны попадать в установщик рядом с `serein.exe`.

## Что готово

1. `crates/zapret` — каталог, рендер, скоуп, обёртка службы, probe.
2. `crates/ui/src/dpi_bypass.rs` + `Page::Dpi` — страница с двумя кнопками,
   статусом и прогрессом; строки в `en-US` и `ru`.
3. `apps/desktop/src/dpi_bypass.rs` — воркер: перебор стратегий, запись
   `run.ps1`, `schtasks /run|/end`, probe, публикация статуса.
4. `packaging/windows/setup-zapret.ps1` — одноразовая регистрация задачи
   `SereinZapret` с `RunLevel Highest` (без UAC при последующих запусках).
5. `packaging/windows/zapret/` — ассеты и `NOTICE.txt`; `cargo xtask package`
   кладёт их в `dist/zapret` и `dist/setup-zapret.ps1`, откуда они попадают и в
   установщик, и в портативный zip.

## Чего не хватает для «просто работает»

- Установщик не вызывает `setup-zapret.ps1` автоматически: пока его нужно
  запустить один раз вручную из папки клиента (или добавить шаг в NSIS).
- Автозапуск задачи при старте Serein не включён: пользователь жмёт
  «Подключить», состояние задачи читается при следующем запуске.
- Локально код не собирался (нет MSVC); первый реальный прогон — CI.

## Правовой статус в РФ (не юридическая консультация)

- **Личное использование** обхода блокировок не запрещено: составов
  «использование VPN/обхода» в КоАП и УК нет, чиновники публично подтверждали,
  что штрафов за само использование VPN не вводят.
- **ФЗ от 31.07.2025 № 281-ФЗ**, с 01.09.2025 — административная
  ответственность за **рекламу и продвижение** сервисов обхода ограничений
  доступа: 50–80 тыс. ₽ для граждан, 80–150 тыс. для должностных лиц,
  200–500 тыс. для юрлиц. Массовая раздача «с рекламой» попадает под это;
  тихий open-source форк для себя — нет.
- Discord в РФ заблокирован с октября 2024; сам факт использования не
  криминализован, но и «права на доступ» нет.
- Использование user-токена в сторонним клиенте нарушает ToS Discord — риск
  блокировки аккаунта, но это не российское право.
- Публичный репозиторий с инструкциями Роскомнадзор может заблокировать по
  правилам о популяризации обхода — размещение на GitHub снижает риск, но не
  убирает его.

## Портативная сборка

`cargo xtask package` кладёт рядом с `serein.exe` папку `zapret\` и
`setup-zapret.ps1`; CI дополнительно упаковывает `dist\*` в
`serein-zapret-portable.zip`. Портативный вариант всё равно требует одного
запуска `setup-zapret.ps1` от администратора: WinDivert без драйвера не
работает, а задача планировщика — единственный способ потом не спрашивать UAC.

## Режимы, свежесть и тишина

- **Авто**: перебор останавливается на первой рабочей стратегии.
- **Вручную**: проверяются все 22, в списке под кнопками остаются краткие
  результаты (`✓ id` / `✗ id`); клик по рабочей строке выбирает её для
  подключения. Выбор и режим живут в состоянии страницы.
- **Свежий zapret**: `.github/workflows/refresh-zapret.yml` ежедневно тянет
  последний релиз Flowseal, перегенерирует `strategies.json` и обновляет
  `packaging/windows/zapret/{bin,lists}`; изменения коммитятся.
- **Свежая Serein**: `.github/workflows/sync-upstream.yml` ежедневно мержит
  `ViceVerse-cz/Serein` в форк; конфликт останавливает job, локальные патчи
  остаются сверху.
- **Без окон**: все дочерние процессы (`schtasks`, `curl`) запускаются с
  `CREATE_NO_WINDOW`, а задача `SereinZapret` регистрируется как `/ru SYSTEM`,
  то есть `winws` живёт в session 0 — ни cmd, ни PowerShell не мелькают.

## Установка без скриптов (для раздачи)

- Пользователь ничего не запускает руками. Установщик после копирования
  файлов вызывает `serein.exe --zapret-install-task` через `ExecShell runas` —
  это единственный UAC, дальше всё молча.
- Портативная сборка делает то же самое сама при первом запуске: приложение
  замечает отсутствие задачи и поднимает UAC через `Start-Process -Verb RunAs`
  своего же exe с флагом `--zapret-install-task`.
- Флаг живёт в `main()` до создания окна: пишет `run.ps1`, регистрирует задачу
  `SereinZapret` (`/ru SYSTEM /rl HIGHEST`) и выходит с кодом 0/1.
- `setup-zapret.ps1` остался только как аварийный вариант, если UAC отклонили.
